# Lumen Sort: public site

Static pages served by GitHub Pages. There is no game source in this repo.

- `index.html`: closed-test landing page (join guide, screenshots, gameplay clip)
- `privacy.html`: privacy policy for the Android app `com.baigames.lumensort`

Before sharing the tester page, replace the placeholder `{{GOOGLE_GROUP_URL}}` in `index.html`. The Play opt-in link (https://play.google.com/apps/testing/com.baigames.lumensort) and the Play listing link (https://play.google.com/store/apps/details?id=com.baigames.lumensort) are already filled in.
