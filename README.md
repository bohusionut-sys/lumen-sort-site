# Lumen Sort: public site

Static pages served by GitHub Pages. There is no game source in this repo.

- `index.html`: closed-test landing page (join guide, screenshots, gameplay clip)
- `privacy.html`: privacy policy for the Android app `com.lumensort.app`

Before sharing the tester page, replace the placeholders `{{GOOGLE_GROUP_URL}}`, `{{PLAY_OPTIN_URL}}` and `{{PLAY_STORE_URL}}` in `index.html`.
